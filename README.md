# 证道 v0.2

一款进行中的修仙题材游戏 demo，致力于用涌现式叙事承载剧情。

## 项目方向

我们想做的不是"被讲述的故事"，而是"在系统中长出来的故事" ——
玩家通过自己的选择参与一个有自己运转逻辑的世界，
每一次重玩都获得新的理解。

## 当前状态

demo 进行中，未发布。

## 技术栈

Godot 4.5 / GDScript

## 仓库布局

- `scripts/` —— 引擎脚本
- `tools/` —— 配置流水线、自动化工具
- `Design/` —— 设计文档（私有 submodule，外部 clone 不可访问）
- `assets/` —— 资源
- `test/` —— 测试
